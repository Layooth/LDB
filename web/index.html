备份与恢复

备份

导出完整快照
把所有表的结构（列、主键、约束）和全部数据打包为一个 JSON 文件下载到本机。大表按 1000 行分批拉取，请耐心等待。

恢复

选择快照文件
选择之前备份的 JSON 文件，恢复前会先解析并展示内容概要
覆盖同名表
勾选后，恢复时同名表会先删除再重建（危险操作，请确认已备份）
开始恢复

说明

· 唯一约束、主键会随建表语句自动重建，无需单独处理索引
· 建议在业务低峰期操作；恢复过程中如果中途失败，已完成重建的表会保留，其余表按日志提示处理
· 定期下载快照到不同的机器存放，单机存放不算真正的备份
